# ESP32 Drone Controller

This is the main application directory for the ESP32 Drone Controller web app.

For complete documentation, installation instructions, and usage guide, please see the **[main README](../README.md)** in the project root.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The application will be available at `http://localhost:5173`
